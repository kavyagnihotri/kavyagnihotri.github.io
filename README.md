# Kavya's Personal Website

A personal portfolio website built with React, TypeScript, and Tailwind CSS.

## Pages

The top navigation links to these pages:

- **Home** (`/`): intro, with the profile card on the right and quick links (GitHub, LinkedIn, Scholar, email, CV)
- **Blogs** (`/blogs`): blog posts and write-ups
- **Art** (`/art`): artworks I like
- **Projects** (`/projects`): selected projects
